# Проба GigaCheck на компьютере с RTX 5080

Бриф для Codex (или человека) на компьютере с видеокартой. Цель — за 3–4 часа понять, можно ли запустить детектор ИИ-текста **GigaCheck-Classifier-Multi** рядом с уже работающими Ollama (GigaChat 3.1 Lightning Q6_K) и сервисом эмбеддингов BERTA. Тексты никуда не отправлять: всё локально.

Основание — `docs/research/ai-text-detection.md` (§2.6 про память, §5.5 вопросы).

## Что сделать

1. **Исходное состояние.** Убедиться, что Ollama с `hf.co/ai-sage/GigaChat3.1-10B-A1.8B-GGUF:Q6_K` и сервис эмбеддингов (порт 8090) запущены. Модель GigaChat должна быть загружена: сделать один запрос к ней. Записать занятую видеопамять по `nvidia-smi`.
2. **Отдельное окружение** для пробы. Работающий сервис эмбеддингов не трогать.
   - Python 3.11 (так требует пакет `gigacheck`).
   - PyTorch со сборкой CUDA 12.8 или новее (cu128): иначе Blackwell sm_120 не работает.
   - transformers, accelerate, bitsandbytes — версия с поддержкой Blackwell и Windows; проверить актуальную.
   - пакет `gigacheck` из GitHub ai-forever.
3. **Загрузить модель** `iitolstykh/GigaCheck-Classifier-Multi` (Hugging Face, Apache-2.0, основа Mistral-7B, `trust_remote_code`) **в 4 битах** (nf4, compute dtype bf16).
4. **Замеры:**
   - пиковая видеопамять всех трёх вместе: GigaChat + BERTA + GigaCheck;
   - время оценки одного текста на 50, 150 и 600 слов и пакета из 16 текстов;
   - не вываливается ли GigaChat из видеопамяти: повторить запрос к Ollama после загрузки GigaCheck и посмотреть `ollama ps`.
5. **Проверка здравого смысла** (по 10 текстов, только локально):
   - 10 настоящих новостей Красноярского края, опубликованных **до 2022 года** (точно написаны людьми), длиной 60–300 слов;
   - 10 текстов на те же темы, сгенерированных локальной GigaChat через Ollama;
   - оценка GigaCheck для каждого текста и сколько ошибок при пороге по умолчанию.
6. **Если не влезает** или GigaChat вытесняется:
   - а) повторить с GigaChat `:Q4_K_M` вместо `:Q6_K` (`ollama pull …:Q4_K_M`);
   - б) если 4 бита не работают на Windows или Blackwell — попробовать 8 бит;
   - в) записать, что сработало.
   Постоянные настройки Ollama и сервиса не менять: только временно на время пробы, потом вернуть.
