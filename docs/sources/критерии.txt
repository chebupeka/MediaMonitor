Раздел 5. Готовность решения — техническая часть, до 15 баллов

Сценарии оценивают завершённость операций. Показ заранее сохранённой подборки не подтверждает
выполнение поиска.

Сценарий 1. Поиск по   Действия пользователя: задать запрос, например        от 0 до 3 баллов
теме, событию или      «Безопасность дорожного движения в Красноярском
человеку               крае», выбрать период и запустить поиск. Затем
                       выполнить поиск по конкретному событию или
                       человеку с уточняющим описанием.

                       Что проверяется: пользователь получает материалы
                       по запросу, видит их количество, источники и
                       выдержки. Система учитывает смысл запроса, а не
                       только совпадение отдельных слов.

Сценарий 2. Поиск по   Действия пользователя: вставить текст новости и       от 0 до 3 баллов
исходной новости       найти её размещения в выбранных источниках. В
                       проверяемом наборе есть исходный текст,
                       сокращённая версия и похожая новость о другом
                       событии.

                       Что проверяется: система находит связанные с
                       исходной новостью публикации. Одинаковый материал
                       на разных ресурсах остаётся в подборке отдельными
                       записями.

Сценарий 3. Изменение  Действия пользователя: выполнить поиск по             от 0 до 3 баллов
периода и источников   выбранному списку ресурсов, затем изменить период
                       и состав источников. Также запустить поиск без
                       ограничения этим списком.

                       Что проверяется: подборка обновляется по новым
                       условиям, а интерфейс показывает, где выполнялся
                       поиск. Если дата публикации неизвестна, система не
                       должна показывать, что материал точно соответствует
                       выбранному периоду.

Сценарий 4. Проверка   Действия пользователя: оценить материалы по           от 0 до 3 баллов
подборки и выгрузка    заголовкам и выдержкам, открыть несколько ссылок и
                       выгрузить подборку.

                       Что проверяется: ссылки ведут на нужные публикации,
                       сведения в результатах поиска совпадают с
                       источниками, а файл содержит ту же подборку.
                       Повторное получение ссылки на тот же пост не создаёт
                       новую запись.
