# 15. Что нужно от команды и что согласовать

Список ведёт лид. Команда разрешила спорное решать по умолчанию, чтобы не останавливать работу (20.10.2026). Здесь собрано всё, что ждёт команду: действия, которые может сделать только она, и решения, принятые по умолчанию.

## Действия команды

| № | Что | Зачем | Как |
|---|---|---|---|
| Д1 | Вписать `EMBEDDINGS_TOKEN` на сервер | Без него компьютер с видеокартой отвечает 401, и отбор по теме идёт только по словам: на стенде тема «БДД» нашла 3 записи | Значение — строка `EMBEDDINGS_TOKEN=…` в `gpu-node\.env` на компьютере с видеокартой (её создал `windows\start.ps1`). На сервере — в `/opt/mediamonitor/app/server/.env`: `set-secret` принимает только ключи VK и MaxStat. Команда ниже |
| Д2 | Поправить бюджет нейросети в `server/.env` стенда | Там остались старые `LLM_CONCURRENCY=1`, `LLM_MAX_GRAY=60`, `LLM_DEADLINE_SEC=300` — они перекрывают новые 4 / 150 / 150 | Удалить эти три строки (тогда действуют значения по умолчанию) — та же команда ниже |

Д1 и Д2 одной командой, со своего компьютера (ввод токена скрыт, в истории команд его не будет):

```
ssh -t team-27@109.196.167.227 'read -rs -p "Вставьте EMBEDDINGS_TOKEN и нажмите Enter: " v; echo; cd /opt/mediamonitor/app/server && sed -i -E "/^(EMBEDDINGS_TOKEN|LLM_CONCURRENCY|LLM_MAX_GRAY|LLM_DEADLINE_SEC)=/d" .env && printf "EMBEDDINGS_TOKEN=%s\n" "$v" >> .env && /opt/mediamonitor/app/server/scripts/update-server.sh'
```
| Д3 | Удалить резервную копию `.env` | В ней секреты; сверено, что в текущем `.env` ни один ключ не пропал (по 61 ключу) | `rm /opt/mediamonitor/app/server/.env.bak-20261020` |
| Д4 | Сменить пароль пользователя team-27 | Пароль был в переписке | `passwd` на сервере |
| Д5 | Результат пробы GigaCheck на компьютере с видеокартой | Без него проверка текста на ИИ на стенде отвечает «проверка недоступна» | `gpu-node/probes/GIGACHECK-PROBE.md` |
| Д6 | Работы под sudo | Безопасность и нормальный адрес | пользователь `gpu-tunnel`, fail2ban, `PasswordAuthentication no`, домен и HTTPS (`docs/10-mockup-backlog.md`, п. 76) |
| Д7 | Сроки и регламент защиты | План презентации | — |
| Д8 | Аккаунты в магазинах расширений | Сегодня расширение ставится из файла (скачать архив → 4 шага). Установка в один клик — только из магазина | Chrome Web Store (через него ставит и Яндекс Браузер): аккаунт разработчика, разовый сбор, проверка обычно 1–7 дней. Каталог Mozilla (Firefox): аккаунт бесплатный, подпись — минуты-часы |

## Решено по умолчанию, ждёт подтверждения

### Сайты СМИ и Дзен (разведка: `docs/research/zen-and-sites.md`)

| № | Вопрос | По умолчанию |
|---|---|---|
| С1 | Порядок подключения | Сначала «Сайты СМИ» (45 из 48 сайтов), Дзен — вторым шагом, за переключателем |
| С2 | Дзен — серая зона (правила запрещают копировать контент, входы недокументированные) | Принимаем, как приняли OK: честно пишем в «паспорте источников» и в интерфейсе |
| С3 | Обновлять ленты сайтов фоном раз в 15 минут? | Нет, по Р7: сбор в момент поиска, база — кэш; глубину 30 дней добираем поиском по сайту |
| С4 | Пользоваться поиском районных сайтов (наши запросы попадут в их статистику) | Да, вежливо: не чаще 1 запроса в секунду на сайт |
| С5 | Лента «Огней Енисея» запрещена в их robots.txt | Не берём, источник помечен честно |
| С6 | Ошибки в таблице источников (замечания у 44 из 48 СМИ: личные страницы VK и OK, приглашения MAX, старые адреса Дзена) | В каталог переносим только корректные; список «уточнить у Агентства» — кто из команды уточнит? |
| С7 | Пользовательские соглашения сайтов не прочитаны: повторную проверку с сервера отклонила система разрешений | Прочитать вручную с российского адреса или разрешить одну проверку с сервера |

### Режим «Везде»

| № | Вопрос | По умолчанию |
|---|---|---|
| В1 | Сервисный ключ VK не даёт искать по всему VK (`newsfeed.search` и `wall.search` — ошибка 1051), поэтому «Везде» для VK — это все сообщества из каталога края (48 СМИ из таблицы и стартовый список), а не весь VK. Для MAX «Везде» — поиск по индексу MaxStat, для сайтов — все сайты каталога | Название оставляем «Везде», в подсказке честно пишем «все краевые источники из каталога». Если нужен поиск по всему VK — нужен другой доступ (ключ пользователя или партнёрский), это отдельное решение |

### Полировка 20.10

| № | Вопрос | По умолчанию |
|---|---|---|
| П1 | После запуска поиска на широком экране (от 1280) пояснение о регионе под формой скрывается, чтобы карта края стала крупной (высота 147 → 282 px на 1440×900) | Скрываем: регион и так показан в строке условий над подборкой |
