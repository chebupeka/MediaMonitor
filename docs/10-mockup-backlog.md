Список, который лид собирает из отчётов исполнителей. Пункты закрываем на этапе сборки и прохода по стилю.

## Контракт API и имитация (зона «Основы» или лида)

1. Метод предпросмотра импорта источников из Excel. Сейчас строки собираются в `screens/sources/demoImport.ts`.
2. Поле задержки в статусе площадки на странице стенда. Сейчас задержка видна только из текста.
3. Метод «перепроверить весь список источников».
4. Типы источников: разделить «краевое СМИ / районное СМИ / госпаблик / городское сообщество» (П13). Сейчас тип и район показаны рядом.
5. Имитация принимает ссылку на пост за группу. Интерфейс ловит это сам, но имитацию нужно поправить.
6. `demoLinks.sourceClosed` уже есть в демо-списке и даёт ответ «уже в списке» — развести.
7. Имитация подбирает набор «Распространения» по словам «школ» и «Норильск», поэтому отдельные абзацы демо-статьи дают «пусто». Сделать подбор устойчивее.
8. Сценарий «Нет связи» роняет связь только на 6 секунд и только при переключении из другого сценария (DemoPanel).

32. В карточке нет «Исключить весь источник» (НТ-25) и «Добавить по ссылке» (П8), хотя API есть. Добавить при проходе по should-пунктам.
