## 5. Прочее

- **«Заполярье»**: по адресу severokrai.ru выходит газета «Северный край» (Норильск). Название в таблице, возможно, устарело.
- **Район не определён** у «Вместе с Вами» и «Сельской жизни». Источник при этом краевой, в поиск по краю он попадает. Районы нужны только для подписи и «Распространения».
- **VK по короткому адресу.** У 25 сообществ в таблице только короткий адрес (`vk.com/avangard_online`), числового id нет. В каталоге ключ такого сообщества — короткий адрес. Когда адаптер VK заработает, он узнает id через `groups.getById`. Агентству ничего делать не нужно.
- **Подписчики в каталоге** взяты из таблицы Агентства, это данные на март 2026. Площадки отдают свои числа при проверке источника.
