# Сообщества VK для поиска: новостные паблики края и федеральные общего плана

**Собрано:** 19.10.2026, с сервера команды, сервисным ключом VK ID (`groups.getById`, `wall.get`).
**Зачем:** с нашим ключом поиск по VK закрыт (`newsfeed.search` и `wall.search` — ошибка 1051), поэтому сервер ищет по списку сообществ: на каждый запрос берёт их последние посты через `wall.get` (`04-decisions.md`, Р2–Р3, Р7). Этот список — стартовый пул.

**Как собирали.** Метода «найти сообщества» с сервисным ключом нет (`groups.search` работает только с ключом пользователя). Поэтому:
1. Проверили через API 194 вероятных коротких адреса — краевые СМИ, городские паблики, власть, города края, федеральные СМИ.
2. Взяли ссылки на VK прямо с сайтов краевых СМИ — так находятся их официальные сообщества.
3. «Снежный ком»: по последним 100 постам найденных краевых сообществ собрали, кого они репостят и упоминают. Из нового это дало в основном кафе и спортклубы, из полезного — «Подслушано в Ачинске».

Подписчики — по данным VK на 19.10.2026. «Живое» — последний пост не старше нескольких дней. Город VK отдаёт сервисному ключу искажённым текстом, но `city_id` верный: **73 — Красноярск**.

[интерпретация] **Федеральные паблики в пул брать осторожно.** О крае они пишут редко, а постов у них много: у РИА за неделю — порядка тысячи, то есть около 10 вызовов `wall.get` на одно сообщество на один поиск. 21 федеральный паблик — это 100–200 вызовов на каждый поиск при лимите 10 000 в месяц без верификации. Разумно: краевой пул целиком плюс 3–5 федеральных (например, ТАСС, РИА Новости, URA.RU) и только за короткий период; после верификации — шире.

## Чего не хватает

- **Не нашли сообщества:** ТВК (сайт не ответил), телеканал «Енисей» (стена закрыта), «Проспект Мира» (на сайте нет ссылки на VK), правительство края (сайт не ответил), «Заполярная правда», «Таймырский телеграф», газеты и паблики районов края. Свои сообщества у «Комсомолки-Красноярск» нет: сайт ведёт на федеральный KP.RU.
- **Лучший источник списка — Агентство.** Оно и так каждый день следит за этими сообществами. Просьба прислать список уже есть в `06-expert-session.md` (блок 3).
- **Быстрый способ дополнить вручную:** человек ищет в VK «Красноярск новости», «<город> новости», «подслушано <город>» с сортировкой по подписчикам и присылает адреса. Сервер проверит их по API: `/opt/mediamonitor/bin/vk-communities <файл>`.

**Скрипты на сервере** (ключ не печатают): `vk-communities` — проверить список адресов; `vk-snowball` — найти сообщества края по репостам и упоминаниям. Результаты — `/opt/mediamonitor/vk-communities.json` и `vk-krai.json`. На сборку ушло около 140 вызовов из месячного лимита.
