# Сайт расширения «Медиарадар»

Витрина продукта и страница скачивания расширения. Весь рабочий функционал — поиск,
подборка, распространение, выгрузка — в расширении (`web/extension`), сайт его не дублирует.

Чистые HTML, CSS и JS без сборки и зависимостей. Структура страницы — по шаблону
«Словарь форм»; точки на WebGL — словарь форм из `docs/08-visual-concept.md`.

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка и тексты страницы |
| `styles.css` | Стили и режимы: тёмная, светлая «чернила», «Тёплый свет», версия для слабовидящих — палитры и цвета точек в переменных `--…` и `--dot-…` в начале файла |
| `prefs.js` | Три кнопки в шапке: тема, «Тёплый свет», версия для слабовидящих; выбор хранится в браузере |
| `fonts/` | Шрифты Fira Sans Extra Condensed и Montserrat (woff2, кириллица и латиница), лицензия SIL OFL 1.1 — без внешних запросов |
| `particles.js` | Точки на WebGL: край и Енисей, мост, «слушает», «ищет», «нашли», распространение, сетка выгрузки, «пусто», «сбой» |
| `ui.js` | Прокрутка, появление текста, счётчики (`data-count`), полосы (`data-fill`) |

## Как открыть

Нужен любой локальный сервер — из `file://` браузер может не дать WebGL и шрифтам загрузиться.
Из корня репозитория:

```bash
python3 -m http.server 8080 --directory site
```

и открыть http://localhost:8080.

## Что ещё заполнить перед сдачей

- «Версия [0.1]» — номер версии расширения.
- «Скачать расширение» ведёт на блок установки; ссылку на ZIP добавить, когда будет релиз.
- Веб-версия открывается по адресу `/app/` на том же сервере — её нужно положить туда при выкладке.
