# Медиарадар

Сотруднику Агентства нужно быстро найти публикации о событии, теме или человеке в VK,
Одноклассниках и MAX по Красноярскому краю за выбранный период, проверить их по прямым
ссылкам и выгрузить подборку в XLSX. Медиарадар делает это одним поиском: вместо ручного
обхода групп и каналов получается подборка с причинами, по которым каждая публикация в неё
попала.

## Как это работает

**Как система получает публикации.** У каждой площадки свой адаптер в
`server/src/mediamonitor/adapters/`. Для VK это VK API (`wall.get` по стенам сообществ), для
OK — публичные страницы групп, для MAX — API MaxStat, для сайтов — RSS-ленты, разделы
новостей и поиск по сайту, для Дзена — страницы каналов. Все адаптеры отдают публикации в
одном формате: текст, дата, прямая ссылка, источник, просмотры. Сбор идёт в момент поиска.
Своя база служит только кэшем: она ускоряет повторный поиск и проверку ссылок, но не
подменяет сбор (решение Р7 в `docs/04-decisions.md`). Если площадка не ответила, найденное на
других площадках сохраняется. У площадки появляется статус «недоступна» или «нет доступа» и
кнопка «Повторить». Ответ, который не удалось разобрать, никогда не превращается в «ничего не
найдено».

**Как система отбирает публикации по смыслу.** Отбор устроен воронкой (`server/matching`):
каждый следующий шаг дороже предыдущего, а до нейросети доходят только спорные посты.
1. Совпадение фраз (шинглы, MinHash) находит копии и сокращённые перепечатки.
2. Модель смысла BERTA находит пересказы и посты на тему, написанные другими словами.
3. Признаки события (места, люди, даты, числа) отсекают похожую новость о другом событии.
4. Спорные посты разбирает GigaChat 3.1 Lightning. Модель работает локально в Ollama, тексты
   не уходят во внешние сервисы. Нейросеть возвращает только метку и номер
   предложения-доказательства из самого поста. Ссылку, дату, заголовок и выдержку система
   берёт только из полученного поста, нейросеть их не пишет.

На мини-эталоне (68 реальных страниц: 4 сюжета края с перепечатками и пересказами и 20
публикаций по двум темам) получились такие точность и полнота подборки: поиск по тексту
новости — 1,00 / 1,00; тема «БДД» — 0,91–0,95 / 1,00 (зависит от того, кто составил карточку
темы: правила или нейросеть); тема «пожарная безопасность» — 1,00 / 1,00.
Темы «БДД» и «пожарная безопасность» не смешиваются. Одно решение нейросети занимает около
0,45 с. Подробности — в `docs/04-decisions.md` («Замер с настоящей GigaChat») и
`server/matching/README.md`.

**Как учитывается регион.** Пост считается краевым, если краевой его источник (сообщество,
группа, канал или сайт из каталога края либо из списка пользователя) **или** в тексте
упомянуто место края: Красноярск, Норильск, районы и так далее. В карточке видна причина:
«краевой источник» или «упоминается: Норильск». Эта же причина попадает в XLSX. В режиме
«Везде» регион служит главным фильтром. В режиме «Мои источники» сотрудник сам выбрал
источники, поэтому регион не проверяется. Регион в прототипе один — Красноярский край. Он
всегда показан в строке условий над подборкой (решение Р4).

**Как исключается повторный учёт.** Одна публикация — одна запись. Ключ записи строится из
площадки, владельца и номера поста (`vk:-100123_4567`). Поэтому разные адреса одного поста
(vk.com, vk.ru, m.vk.com, `?w=wall…`) и повторное получение ссылки сливаются в одну запись и
не увеличивают счётчик. Прямую ссылку система строит из этого ключа, а не берёт из текста.
Если пост в одном источнике повторяется дословно, его отсекает хеш текста. Одинаковый
материал в разных группах и каналах — это разные размещения: каждое считается отдельно и
имеет свою ссылку. Такие размещения собираются в группу «Релиз „…“ — N размещений», и внутри
группы доступны все ссылки (решение Р9, раздел 3 в `docs/12-tech-design.md`).

### Локально, без ключей

На записанных примерах (`DATA_SOURCE=fixtures`) сервер работает без ключей площадок,
нейросети и видеокарты.

```bash
cd server
cp .env.example .env
# в .env: POSTGRES_PASSWORD=<любой>; PUBLIC_APP_URL=http://127.0.0.1:8000/app/
# вне РФ сайты края не открываются: SITES_SOURCE=fixtures, DZEN_SOURCE=fixtures
docker compose up -d --build     # база → миграции → API; собирает и сайт, и веб-версию
curl http://127.0.0.1:8000/health
```

После запуска сайт открывается на http://127.0.0.1:8000/, а веб-версия — на
http://127.0.0.1:8000/app/. При первом запуске скачивается модель BERTA (~0,5 ГБ). Чтобы
обойтись без модели, задайте `MATCHER=mediamonitor.matcher.simple:create_matcher` (это
упрощённый отбор по словам). Запуск без Docker через `uv run` описан в `server/README.md`.

Интерфейс отдельно (`web/`):

```bash
cd web
npm install
npm run dev                                   # мокап на демо-данных: http://localhost:5173
npm run build:web && npx vite preview --mode web   # веб-версия с локальным сервером: http://localhost:4173/app/
VITE_API_URL=http://127.0.0.1:8000 npm run ext:build   # расширение для локального сервера → .output/chrome-mv3/
```

Без `VITE_API_URL` расширение собирается для стенда.

Проверки:

```bash
# из корня репозитория
(cd server && uv run pytest)                 # сервер: временная база SQLite, лёгкая модель вместо BERTA
(cd server/matching && uv run pytest)        # воронка отбора, без сети и без загрузки моделей
(cd gpu-node && uv run --extra cpu pytest)   # сервис эмбеддингов и детектор, без видеокарты
(cd web && npm run typecheck && npm run lint && npm run check:ai && npm run check:web)
```

Линтеры, mypy, тесты на PostgreSQL и медленный тест с настоящей BERTA описаны в
`server/README.md`, раздел «Проверки». Оценка отбора на мини-эталоне — в
`server/matching/README.md`.

## Доступы и ключи

Значений ключей в репозитории нет. Тест проверяет, что в репозиторий не попало ничего
похожего на ключ. Полный список переменных — `server/.env.example`.

| Переменная | Зачем | Где хранится | Что будет без неё |
|---|---|---|---|
| `VK_SERVICE_TOKEN` | сервисный ключ приложения VK ID для VK API | на сервере, `/opt/mediamonitor/.env` (права 600, скрипт `set-secret`) | VK: «нет доступа»; остальные площадки работают |
| `MAXSTAT_API_TOKEN` (запасное имя `MAXSTAT_TOKEN`) | поиск по MAX через MaxStat | там же | MAX: «нет доступа» |
| `OLLAMA_URL`, `LLM_MODEL` | нейросеть GigaChat 3.1 Lightning в Ollama | `server/.env` на сервере | спорные посты остаются в подборке с пометкой «не проверено ИИ» |
| `EMBEDDINGS_URL`, `EMBEDDINGS_TOKEN` | сервис эмбеддингов на компьютере с видеокартой; токен общий с детектором | `server/.env` на сервере и `gpu-node/.env` | локально BERTA считается на CPU сервера. На стенде (образ без torch) отбор идёт без смысловой близости, на странице стенда появляется предупреждение |
| `AI_DETECT_URL` | детектор ИИ-текста GigaCheck | `server/.env` на сервере | «проверка недоступна» |
| `POSTGRES_PASSWORD`, `DATABASE_URL` | база | `server/.env` | сервер не запустится |
| `PUBLIC_APP_URL`, `CORS_ORIGINS` | адрес интерфейса, от которого строится ссылка-ключ; адреса, с которых браузеру разрешены запросы | `server/.env` | ссылка-ключ рабочего места строится от адреса по умолчанию (`http://localhost:5173/`) |

OK, сайты СМИ и Дзен работают без ключей. Логины пользователей и экспертов система не
хранит и никуда не передаёт. Рабочее место открывается по ссылке-ключу, а в базе хранится
только хеш ключа.

**Какие данные уходят наружу** (подробно — паспорт источников в `server/README.md`):
- в VK — id сообществ;
- в OK — адреса страниц групп и постов; запрос пользователя в OK не уходит;
- в MaxStat — текст запроса и даты;
- на сайты СМИ — слова запроса для поиска по сайту, и только когда RSS-лента не покрывает
  период;
- в Дзен — имя или id канала;
- на компьютер команды с видеокартой (через SSH-туннель) — тексты постов для эмбеддингов,
  нейросети и детектора.

Во внешние ИИ-сервисы тексты не уходят.

## Расходы и лимиты

| Что | Лимит | Сколько тратит один поиск | Цена |
|---|---|---|---|
| VK API | у площадки — 10 000 вызовов в месяц без верификации; бюджет стенда — 1 500 вызовов в сутки и 10 000 в месяц (`VK_DAILY_CALLS`, `VK_MONTHLY_QUOTA`) | «Везде» за 7 дней — около 70 вызовов, за 30 дней — около 90–120. Повтор в течение 30 минут обходится без вызовов (кэш) | бесплатно в пределах лимита |
| MaxStat (MAX) | бесплатный тариф — 1 000 кредитов в 30 дней; бюджет стенда — 150 кредитов в сутки и 1 000 в месяц (`MAXSTAT_DAILY_CREDITS`, `MAXSTAT_CREDITS`) | не больше 14 кредитов: до 3 страниц по 3 кредита и до 5 запросов канала по 1 кредиту. Повтор в течение 60 минут берётся из кэша | бесплатно; сверх лимита — от 990 ₽ за 20 000 кредитов |
| OK, сайты СМИ, Дзен | вежливая частота: OK — 1 запрос в 1,1 с на весь сервер, сайты — 1 запрос в секунду на сайт | запросы страниц, без денег | бесплатно |
| Нейросеть, эмбеддинги, детектор | бюджет на поиск — 150 спорных постов и 150 с | — | свой компьютер команды с видеокартой; подписок на внешние ИИ нет |

Когда квота исчерпана, у площадки появляется статус «лимит на сегодня исчерпан». При расходе
80% квоты в журнал стенда пишется предупреждение. Расход видно на странице стенда. Эксперту
ничего покупать не нужно.

**Почему не Яндекс.** ТЗ рекомендует рассмотреть нейросети Яндекса, и мы их рассмотрели. В
октябре 2026 Yandex Cloud работает в ограниченном режиме, новым клиентам не дают гранта, а
модели выводятся из эксплуатации по графику. Локальная модель бесплатна, и тексты не покидают
наши компьютеры. Модель подключается через OpenAI-совместимый интерфейс, поэтому провайдера
можно сменить настройкой `LLM_API` (решение Р5–Р6 в `docs/04-decisions.md`).

## Ограничения

- **VK:** поиска по всему VK нет, только по стенам 66 сообществ каталога. У федеральных
  сообществ берутся последние 100 постов. Неподтверждённое приложение VK блокируется через
  60 дней. Для работы в Агентстве нужно письменное согласие VK (п. 2.4 Правил платформы) и
  своё приложение VK ID на Агентство.
- **OK:** берутся только 10 последних постов группы, просмотров нет. При первом поиске полный
  текст и точная дата есть только у части постов, у остальных — начало текста и дата «≈».
  Площадка в серой зоне по правилам.
- **MAX:** индекс MaxStat отстаёт до ~24 часов. Посты каналов без короткого имени
  пропускаются. MaxStat — сторонний сервис, и он может изменить свой API.
- **Сайты и Дзен:** из 48 сайтов подключено 43. Сайты края открываются только с адреса в РФ.
  Дзен в серой зоне по правилам. Источники не из каталога в первой версии не поддерживаются.
- **Регион** один — Красноярский край. Период поиска — до 183 дней, запрос — до 20 000 знаков.
  Одно рабочее место ведёт один поиск за раз.
- **Проверка текста на ИИ** на стенде пока не подключена.
- **Стенд** работает по HTTP без домена. Расширение ставится из архива в режиме
  разработчика, в Firefox — до перезапуска браузера.
- **Нейросеть:** карточка темы кэшируется в памяти, поэтому после перезапуска сервера она
  может измениться. Если компьютер с видеокартой недоступен, спорные посты помечаются «не
  проверено ИИ».
- Пользовательские соглашения сайтов СМИ не проверены. Что уточнить у Агентства по каталогу
  источников — `docs/research/catalog-issues.md`.
